# GFAz poster — HTML/CSS build

42 in × 45 in, portrait. Renders to an exact-size print PDF via headless Chrome.

## Files

| File | What it is |
|---|---|
| `build.py` | Generates `poster.html`. **All data lives here** — edit the tables at the top, not the HTML. |
| `poster.html` | Generated. Open in a browser to preview/iterate. |
| `poster.pdf` | Print deliverable, 3024 × 3240 pt = exactly 42 × 45 in. |
| `poster-print-outlined.pdf` | Same, text converted to vector outlines. Use if the print shop chokes on Type 3 fonts. |
| `render.js` | HTML → PDF at exact page size. |
| `measure.js` | Reports content height vs. the 45 in page and flags clipped elements. Run this before rendering. |
| `qr-*.png` | QR codes (repo + DOI), 620 px. |

## Build

Needs `puppeteer` (bundles its own Chromium):

```bash
npm install puppeteer          # once
python3 build.py               # -> poster.html
node measure.js poster.html    # check nothing overflows; OVERFLOW must be <= 0
node render.js poster.html poster.pdf
```

Optional, for the outlined variant:

```bash
gs -o poster-print-outlined.pdf -sDEVICE=pdfwrite -dNoOutputFonts \
   -dPDFSETTINGS=/prepress -r600 poster.pdf
```

## Notes

- Numbers come from the repo `README.md` as of commit *Refresh CPU compression
  benchmarks* (CPU figures are 32 threads, end-to-end CLI wall time). The paper's
  §4 table still carries the older 16-thread numbers — they do not match.
- Fonts (Archivo / Inter / JetBrains Mono) load from Google Fonts, so the render
  needs network access. Chrome embeds them into the PDF.
- Charts are inline SVG generated by `build.py`, so they stay vector in print.
  The only raster content is the two QR codes (428 ppi at print size).
- Layout is flexbox with `.spacer` elements absorbing slack. If you add content,
  re-run `measure.js` — the page silently clips overflow rather than erroring.
